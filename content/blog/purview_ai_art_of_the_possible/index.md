{{< gridjs-md wide="true"  title="DLP Enforcement Scenarios" >}}

| Scenario | Category | Enforcement Plane | Mechanism | Scope / Coverage | Actions Available | License | Notes | Docs |
|---|---|---|---|---|---|---|---|---|
| File uploads to cloud/web | Egress - Upload | Endpoint DLP | Upload to restricted cloud service domain | Onboarded Windows 10/11, macOS devices | Audit, Block, Block w/ Override | E5 / E5 Compliance | Requires Purview Chrome Extension for Chrome/Firefox; Edge native | [↗](https://learn.microsoft.com/en-us/purview/endpoint-dlp-learn-about) |
| File uploads to cloud/web | Egress - Upload | Edge In-Browser DLP | Inline browser enforcement via Edge for Business | Windows devices using Edge for Business (onboarded or non-onboarded) | Audit, Block, Block w/ Override | E5 / E5 Compliance | Non-onboarded device coverage in preview; requires Edge for Business | [↗](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-security-dlp) |
| File uploads to cloud/web | Egress - Upload | Network Data Security | SASE integration inspects network traffic (e.g., Entra GSA Internet Access) | All network traffic via integrated SASE provider | Block, Alert | PAYG + SASE provider | Covers unmanaged cloud apps, AI tools (ChatGPT, Gemini, etc.); requires SASE integration | [↗](https://learn.microsoft.com/en-us/purview/dlp-network-data-security-learn) |
| File uploads to cloud/web | Egress - Upload | Defender for Cloud Apps (CASB) | Session policy via Conditional Access App Control | Cloud apps proxied through Defender for Cloud Apps | Block upload, Monitor, Require step-up auth | Defender for Cloud Apps (M365 E5 / E5 Security) | Requires app to be session-controlled; covers 34,000+ catalogued apps | [↗](https://learn.microsoft.com/en-us/defender-cloud-apps/session-policy-aad) |
| Email with sensitive content | Egress - Email | Exchange Online DLP | Purview DLP policy scoped to Exchange location | Exchange Online (inbound and outbound) | Block, Notify, Encrypt, Add disclaimer, Redirect, BCC | E3+ | Works alongside mail flow rules; mail flow rules processed first and take precedence | [↗](https://learn.microsoft.com/en-us/purview/dlp-exchange-conditions-and-actions) |
| Email with sensitive content | Egress - Email | Exchange Mail Flow Rules (Transport Rules) | EAC transport rules evaluated before Purview DLP | Exchange Online | Block, Redirect, Add header, Encrypt, Quarantine | E3+ | Processed before Purview DLP; messages blocked here are not scanned by DLP | [↗](https://learn.microsoft.com/en-us/purview/dlp-how-dlp-works-between-admin-centers) |
| Email with sensitive content | Egress - Email | Network Data Security | SASE integration monitors network-level traffic to cloud mail providers | Cloud email providers (e.g., Gmail) via network | Block, Alert | PAYG + SASE provider | Covers personal/shadow email providers outside M365 | [↗](https://learn.microsoft.com/en-us/purview/dlp-network-data-security-learn) |
| Copy to USB / removable media | Egress - Device | Endpoint DLP | Copy to removable USB device activity | Onboarded Windows 10/11, macOS devices | Audit, Block, Block w/ Override | E5 / E5 Compliance | Can allow specific approved USB devices via removable storage device groups | [↗](https://learn.microsoft.com/en-us/purview/endpoint-dlp-learn-about) |
| Copy to network share | Egress - Device | Endpoint DLP | Copy to network share activity on onboarded devices | Onboarded Windows 10/11, macOS devices | Audit, Block, Block w/ Override | E5 / E5 Compliance | Can scope to specific network share groups; VPN vs. corporate network exceptions available | [↗](https://learn.microsoft.com/en-us/purview/endpoint-dlp-learn-about) |
| Printing sensitive documents | Egress - Device | Endpoint DLP | Print activity monitoring on onboarded devices | Onboarded Windows 10/11, macOS devices | Audit, Block, Block w/ Override | E5 / E5 Compliance | Can scope to specific printer groups (network vs. local) | [↗](https://learn.microsoft.com/en-us/purview/endpoint-dlp-learn-about) |
| Printing sensitive documents | Egress - Device | Edge In-Browser DLP | Print protection for labeled content viewed in Edge for Business | Content opened in Edge for Business (Office Online) | Block print based on sensitivity label | E5 / E5 Compliance | Enforces MIP label-based print restrictions for content in browser | [↗](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-security-dlp) |
| Copy/paste sensitive content | Egress - Device | Endpoint DLP | Copy to clipboard + Paste to supported browsers activities | Onboarded Windows 10/11 devices | Audit, Block w/ Override (silent Block unreliable for paste) | E5 / E5 Compliance | Silent block unreliable for browser paste; Block w/ Override works; Edge has deepest integration | [↗](https://learn.microsoft.com/en-us/purview/dlp-policy-reference) |
| Copy/paste sensitive content | Egress - Device | Edge In-Browser DLP | Copy/paste blocked for sensitivity-labeled content in Edge for Business | Labeled documents opened in Edge for Business (Office Online) | Block copy/paste based on sensitivity label | E5 / E5 Compliance | MIP label conditions; enforced for Office Online in browser | [↗](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-security-dlp) |
| Data exfiltration via RDP session | Egress - Device | Endpoint DLP | Clipboard and file activity monitoring extends to RDP sessions | Onboarded Windows devices in RDP sessions | Audit, Block w/ Override (clipboard) | E5 / E5 Compliance | Clipboard controls apply cross-app including RDP; file activity also monitored | [↗](https://learn.microsoft.com/en-us/purview/endpoint-dlp-learn-about) |
| Access by unauthorized/restricted apps | Egress - Device | Endpoint DLP (Restricted App Activities) | Restrict specific apps from accessing sensitive files | Onboarded Windows 10/11, macOS devices | Audit, Block (all access blocked), Block w/ Override | E5 / E5 Compliance | Blocked app cannot perform any file activities on matched sensitive items | [↗](https://learn.microsoft.com/en-us/purview/dlp-policy-reference) |
| Sharing in SharePoint / OneDrive | Collaboration - Sharing | SharePoint / OneDrive DLP | DLP policy scoped to SharePoint / OneDrive locations | SharePoint Online sites and OneDrive accounts | Block external access, Block everyone, Notify, Apply label | E3+ | Applies to sites, not users; proactively blocks guests upon detection regardless of sharing state | [↗](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) |
| Sharing in SharePoint / OneDrive | Collaboration - Sharing | Sensitivity Labels (Container / Site Labels) | Sensitivity label applied to site enforces external sharing settings | SharePoint sites, Teams, M365 Groups | Restrict external sharing, Control guest access | E3+ for consumption; AIP P1/P2 or E5 to publish labels | Label policy setting, not a DLP policy; controls SharePoint sharing settings at container level | [↗](https://learn.microsoft.com/en-us/purview/sensitivity-labels-teams-groups-sites) |
| Oversharing via 'Anyone with link' | Collaboration - Sharing | SharePoint / OneDrive DLP | Policy detects and restricts 'Anyone' or external sharing links | SharePoint Online, OneDrive for Business | Block sharing, Restrict access, Notify | E3+ | Applies site-level; can combine with sensitivity label as condition | [↗](https://learn.microsoft.com/en-us/purview/dlp-learn-about-dlp) |
| Teams chat / channel messages | Collaboration - Messaging | Teams DLP | DLP policy scoped to Teams chat and channel messages | Teams chat and channel messages (text only, incl. private channels); file sharing covered by SPO/OD DLP | Block message, Notify sender | E5 (Teams chat DLP); E3 covers files in Teams via SharePoint/OneDrive DLP | No email notifications (in-chat flags only); Block or Allow only — no user override option | [↗](https://learn.microsoft.com/en-us/purview/dlp-microsoft-teams) |
| Sensitive data in AI / Copilot prompts | AI / Copilot | DSPM for AI (DLP policy templates) | One-click DLP policy templates targeting Microsoft 365 Copilot interactions | Microsoft 365 Copilot (Word, Excel, Teams, etc.) | Block, Audit, Policy tip | E5 / E5 Compliance | Uses existing DLP SIT/label conditions; surfaces in DSPM for AI dashboard | [↗](https://learn.microsoft.com/en-us/purview/ai-microsoft-purview) |
| Sensitive data in AI / Copilot prompts | AI / Copilot | Endpoint DLP (Sensitive Service Domain Groups) | Upload/paste restrictions to AI sites via sensitive service domain groups | Onboarded devices; Edge, Chrome (extension), Firefox (extension) | Audit, Block, Block w/ Override | E5 / E5 Compliance | Built-in Generative AI Websites group; used by DSPM for AI default policies | [↗](https://learn.microsoft.com/en-us/purview/dlp-configure-endpoint-settings) |
| Sensitive data in AI / Copilot prompts | AI / Copilot | Network Data Security | SASE integration blocks sensitive content sent to unmanaged AI apps | All unmanaged AI apps via network — ChatGPT, Gemini, Claude, etc. | Block text / file upload, Alert | PAYG + SASE provider | Covers third-party AI tools outside M365; requires Entra GSA Internet Access or partner SASE | [↗](https://learn.microsoft.com/en-us/purview/dlp-create-policy-ai-network-data-security) |
| On-premises file shares / SharePoint Server | On-Premises | AIP Scanner (Purview Information Protection Scanner) | Scans on-prem file shares and SharePoint Server; discovers, labels, and protects | SMB file shares, SharePoint Server 2013–2019 | Discover, Auto-label, Apply protection (encryption) | AIP P2 / E5 Compliance | Not a real-time DLP enforcement engine; focused on discovery and labeling | [↗](https://learn.microsoft.com/en-us/purview/deploy-scanner) |
